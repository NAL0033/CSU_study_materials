# 任务二：单周期 MIPS 处理器设计 — 实现计划与讲解

## 一、参考电路总览

附件提供的 `CPU.circ` 是一个完整可用的单周期 MIPS 处理器，共包含 **13 个子电路模块**：

| 模块 | 功能 |
|------|------|
| **main** | 顶层电路，连接所有数据通路 |
| **IM** | 指令存储器（ROM），存放机器码 |
| **DM** | 数据存储器（RAM），存放运行时数据 |
| **GRF** | 通用寄存器组（32×32位），含读写端口 |
| **GRF2** | 寄存器组的另一实现版本 |
| **IFU** | 取指令单元，管理 PC 更新 |
| **Controller** | 主控制器，指令译码→控制信号 |
| **ALUControl** | ALU 控制，生成 ALU 操作码 |
| **ALU** | 32 位算术逻辑单元 |
| **4bitalu** | 4 位 ALU（1位ALU的级联基础） |
| **EXT** | 符号/零扩展模块 |
| **Zero_EXT** | 16→32 位零扩展 |
| **Shift** | 移位模块（分支地址计算） |

---

## 二、数据通路架构（main 电路）

参考电路采用的是**经典单周期 MIPS 数据通路**，一条指令在一个时钟周期内完成全部5个阶段：

### 2.1 取指阶段 (IF)

```
PC寄存器 → IM（指令存储器） → 输出32位指令字
PC+4 加法器 → 下一条顺序指令地址
```

### 2.2 译码阶段 (ID)

```
指令字按 MIPS 格式切分：
  - opcode[31:26] → Controller（主控）
  - rs[25:21]     → GRF 读地址1
  - rt[20:16]     → GRF 读地址2 / MUX选择
  - rd[15:11]     → RegDst MUX → GRF 写地址
  - func[5:0]     → ALUControl
  - imm[15:0]     → EXT 符号/零扩展
```

### 2.3 执行阶段 (EX)

```
ALU 输入A = GRF读数据1 (RD1)
ALU 输入B = ALUSrc MUX(RD2 或 扩展后的立即数)
ALU 操作码 ← ALUControl(ALUOp, func码)
```

### 2.4 访存阶段 (MEM)

```
DM 地址 = ALU结果
DM 写数据 = GRF读数据2 (RD2)   [仅 sw]
DM 读数据 = MemData            [仅 lw]
```

### 2.5 写回阶段 (WB)

```
MemtoReg MUX → 选择 ALU结果/DM数据/移位数据 → GRF 写数据
RegWrite 信号 → 控制是否写入 GRF
```

## 三、指令集与控制信号

参考电路支持的全部 8 条指令（含 nop）：

| 指令 | 类型 | opcode | func | 关键控制信号 |
|------|------|--------|------|-------------|
| **addu** | R | 000000 | 100001 | RegDst=1,ALUSrc=0,RegWrite=1,ALUOp=000 |
| **subu** | R | 000000 | 100011 | RegDst=1,ALUSrc=0,RegWrite=1,ALUOp=000 |
| **ori**  | I | 001101 | — | RegDst=0,ALUSrc=1,RegWrite=1,EXTOp=0,ALUOp=011 |
| **lw**   | I | 100011 | — | RegDst=0,ALUSrc=1,RegWrite=1,MemRead=1,EXTOp=1 |
| **sw**   | I | 101011 | — | ALUSrc=1,MemWrite=1,EXTOp=1 |
| **beq**  | I | 000100 | — | Branch=1,ALUOp=001(sub) |
| **lui**  | I | 001111 | — | RegDst=0,ALUSrc=1,RegWrite=1,EXTOp=0,MemtoReg=01 |
| **nop**  | — | 000000 | 000000 | 全 0 = 无有效操作 |

### 控制信号一览

| 信号 | 位宽 | 含义 |
|------|------|------|
| **RegDst** | 1 | 0=rt目的寄存器, 1=rd目的寄存器 |
| **ALUSrc** | 1 | 0=RD2, 1=立即数 |
| **MemtoReg** | 2 | 00=ALU结果, 01=移位结果, 10=内存数据 |
| **RegWrite** | 1 | 写寄存器使能 |
| **MemRead** | 1 | 读内存使能 |
| **MemWrite** | 1 | 写内存使能 |
| **Branch** | 1 | 分支使能 (PCSrc = Branch & Zero) |
| **EXTOp** | 1 | 0=零扩展, 1=符号扩展 |
| **ALUOp** | 3 | ALU 操作码 |

## 四、分步实现计划（模块化自底向上）

### 第 1 步：4 位 ALU（4bitalu）★ 基础模块

- **先实现 1 位 ALU**：支持 AND、OR、ADD（含进位）、SUB、SLT
- 级联 4 个 1 位 ALU → 4 位 ALU
- 处理进位链和溢出

### 第 2 步：32 位 ALU

- 级联 8 个 4 位 ALU（或直接级联 32 位）
- 支持操作：`addu`（加）、`subu`（减）、`OR`（或）、`LUI`（移位16位）
- ALU 输出 Zero 标志（用于 beq）

### 第 3 步：寄存器组（GRF）

- 32 个 32 位寄存器
- 2 个读端口（rs → RD1, rt → RD2）
- 1 个写端口（RegWrite 控制）
- **$0 寄存器恒为 0**

### 第 4 步：扩展模块（EXT + Zero_EXT）

- **Zero_EXT**：16 位 → 32 位零扩展（高位补 0，用于 ori / lui）
- **EXT**：根据 EXTOp 选择符号扩展（用于 lw/sw/beq）或零扩展

### 第 5 步：指令/数据存储器

- **IM**（ROM）：足够容量存放测试程序（如 32×32 位）
- **DM**（RAM）：读写数据存储器

### 第 6 步：移位模块（Shift）

- 将 32 位立即数左移 2 位
- 用于 beq 分支目标地址的低 16 位拼接

### 第 7 步：控制器（Controller + ALUControl）

- **Controller**：6 位 opcode 输入 → 9 个控制信号输出
  - 纯组合逻辑（与门+非门+或门）
  - 每个指令对应一个 AND 门检测特定 opcode+func 组合
- **ALUControl**：3 位 ALUOp + 6 位 func → 3 位 ALU 操作码
  - 区分 addu/subu/ori/lui/lw/sw/beq

### 第 8 步：取指单元（IFU）

- PC 寄存器（32 位）
- PC+4 加法器
- 分支地址计算：`PC+4 + sign_ext(imm)×4`

### 第 9 步：顶层电路（main）★ 连线

将所有模块按数据通路连接：

1. PC → IM → 指令字段切分（Splitters）
2. rs/rt → GRF；rd/rt → RegDst MUX → GRF 写地址
3. RD1 → ALU A；RD2/EXT → ALUSrc MUX → ALU B
4. ALU 结果 → DM 地址 / 写回 MUX
5. DM 输出 / ALU 结果 → MemtoReg MUX → GRF 写数据
6. Zero 标志 & Branch → AND → PCSrc MUX

### 第 10 步：测试验证

1. 编写测试程序（汇编 → 机器码）
2. 填入 IM（ROM）
3. 逐个运行，观察关键信号和数据流
4. 验证每条指令的正确性

```
4bitalu → ALU ────────────────┐
                               ├→ Controller → main(连线) → 测试
GRF → EXT → Zero_EXT → Shift ─┤
                               │
IM → DM → IFU ────────────────┘
```

## 六、关键提示

1. 参考电路的 **Controller** 和 **ALUControl** 是硬连线逻辑，用 AND 门阵列检测每种指令的 opcode+func 组合。可以直接采用这种方式，也可以用 ROM+PLA 方式实现。
2. 顶层 main 电路中的标签（如 "Adder"、"Nadd"、"Branch"、"Zero" 等）可帮助你定位各组件的功能。
3. 实验报告需要截图展示每个模块的**内部电路**以及**顶层连线**，建议每完成一个模块就截图保存。
4. `add` 和 `sub` 指令作为 `addu`/`subu` 的变体支持（溢出检测版本的机器码不同，但在 Logisim 中可共用 ALU 逻辑）。
5. Logisim 程序位于 `D:\MyFiles\Downloads\logisim-win-2.7.1.exe`，需先安装 Java 运行环境。
