# 贪婪搜索与 A* 搜索算法可视化演示

## 1. 项目简介

本项目使用 **Pygame** 实现了一个路径搜索算法可视化程序，用于对比：

- **贪婪最佳优先搜索（Greedy Best-First Search）**
- **A\* 搜索算法（A\* Search）**

程序以网格地图为基础，展示两种算法从起点 `S` 到终点 `G` 的搜索过程，并通过颜色、分数标注和统计信息，直观比较两种算法在路径规划中的表现差异。

本项目对应课程作业题目中的：

> **选项C：算法对决：贪婪 vs A\***

---

## 2. 功能说明

本程序支持以下功能：

- 展示网格地图中的起点、终点、障碍物和可通行区域
- 可视化 Greedy 与 A\* 的搜索过程
- 显示节点的 `g / h / f` 信息
- 显示 OPEN / CLOSED 集合变化
- 显示最终路径
- 统计并展示：
  - 扩展节点数
  - 路径长度
  - 运行时间
  - OPEN 表最大规模
- 支持三种视图模式：
  - `both`：双算法对比
  - `Greedy`：仅显示贪婪算法
  - `A*`：仅显示 A\* 算法
